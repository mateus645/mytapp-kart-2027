# myTapp Kart 2027

Kart em 3D low-poly: 4 pistas, itens, um especial por piloto e a Copa myTapp (as 4 pistas seguidas). Jogue pelo link do
GitHub Pages. Para rodar no computador, sirva a pasta (por exemplo `python3 -m http.server`) e abra o endereço no
navegador; aberto direto do disco (file://), o navegador não carrega o three.js.

- Teclado: ↑ acelera, ↓ freia e dá ré, ← → viram, Espaço faz o drift (solte para o turbo), X usa o item, C solta o
  especial, Esc pausa.
- Celular: botões na tela.
- O jogo roda todo nesta pasta: sem login, sem servidor, sem rede e sem coleta de dados. O recorde fica só no seu
  aparelho.
- three.js 0.160.0 (MIT): `three-0.160.0.module.min.js` e `three-0.160.0.BufferGeometryUtils.js`, licença em
  `three.LICENSE`.
